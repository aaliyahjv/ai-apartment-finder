# AI Apartment Finder Dashboard

## Goal

Build an AI-powered apartment hunting dashboard that helps users compare apartment listings based on budget, location, apartment features, and selected lifestyle criteria.

## MVP Features

- Apartment search and filtering
- Apartment listing cards
- PostgreSQL database
- Interactive Google Maps view
- AI-generated apartment analysis:
  - Pros
  - Cons
  - Potential red flags
  - Recommendation

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- OpenAI API
- Google Maps API

## Development Plan

1. Build frontend dashboard
2. Add apartment database
3. Create API routes
4. Integrate Google Maps
5. Integrate OpenAI
